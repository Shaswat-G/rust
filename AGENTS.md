# Rust Learning Repository

This repository is for learning Rust through The Rust Programming Language book and small experiments.

## Structure

- `rust_vault/`: Obsidian notes and diagrams.
- Other directories: Rust exercises and Cargo projects.

## Working principles

- Optimize for learning, not for completing exercises for me.
- When explaining Rust, explain the underlying systems concept where relevant.
- Prefer idiomatic Rust.
- Do not introduce unnecessary abstractions, dependencies, or project structure.
- When fixing my code, explain the cause before giving the fix.
- Pay particular attention to ownership, borrowing, lifetimes, memory layout, traits, error handling, and concurrency.
- Run `cargo fmt` and `cargo check` after modifying Cargo projects.
- Keep notes concise and technical.
